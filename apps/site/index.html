    Agents propose, policy decides

    The defender agents reason with NVIDIA Nemotron, self-hosted on-prem, so telemetry stays in the building. SpacetimeDB holds the incident as rows, live on every operator’s console.

    • Static SOAR playbooks

      Match attacks they have already seen, then run fixed steps.

    • Claura’s agents

      Assemble evidence on attacks nobody has seen and propose bounded actions. Every action passes a policy gate before it runs. Policy, not the model, decides what executes.
