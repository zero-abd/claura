60,000 sandboxed agents. One of them breaks out.

A guest-to-host escape through the vGPU path puts its neighbours and the management plane within reach.

A static playbook has never seen it.

Playbooks only match attacks they have already seen. This one is new.

The on-call engineer is asleep.

Every minute spent waking someone, finding the host and deciding what to cut is a minute the breach spends spreading.

Four agents. One human.

Each agent has one job. The one high-impact step stays with a person.

  1. Sentry spots the escape.

    It correlates IOMMU faults, hypervisor audit logs, host EDR, IPMI flows and token misuse into a single incident.

    • IOMMU faults
    • Hypervisor audit logs
    • Host EDR
    • IPMI flows
    • Token misuse
    INC-0419 critical Suspected guest-to-host escape

  2. Triage sizes the blast radius.

    One suspect host, 11 co-resident guests and a reachable management plane. Triage scores what the escape could touch before anything moves.

    1
    suspect host
    11
    co-resident guests
    Reachable
    management plane

  3. Warden seals it, reversible steps first.

    Cut the network, revoke credentials, cordon the host. Then pause the guest, capture its memory and fail the guests over to clean hosts.

    Reversible first

    1. Isolate networkT+2.4 s

    Quarantine host waits for a person

  4. Scribe writes the timeline.

    A forensic record of every signal, action and approval, kept while the others work.

  5. You make the one call.

    Quarantining the host is the single high-impact step. Evidence, scope and rollback sit on one card. Approve with ⌘↵.

    Quarantine host b14-gpu-07

    Proposed by Warden · policy-bounded

    Needs approval

    Warden: qemu on this host spawned a shell after a DMA fault. Treat the host as untrusted until it is reimaged.

    Evidence
    6 correlated signals: IOMMU fault, vGPU mdev fault, VMM ioctl, qemu → /bin/sh, IPMI flow, token misuse
    Scope
    1 host · 11 guests failed over
    Rollback
    Un-quarantine restores the host to the pool

    Warden cannot quarantine a host on its own.
